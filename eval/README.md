# Evaluation

Two evaluation tracks: the **official BabyLM 2026 pipeline** (leaderboard
format) and our **VP-Swap** visual-property benchmark. Current results:
[`official_results.md`](official_results.md) and
[`vpswap_results.md`](vpswap_results.md) (both generated by the analysis
scripts below). Figures in [`plots/`](plots/).

## A. Official BabyLM 2026 evaluation (runbook)

One-time setup (Snellius login node):
1. Eval harness: `~/babylm-eval` = fork `bylinina/babylm-eval`, synced with
   `babylm-org/babylm-eval` upstream. Our compat patches (tokenizer
   fallbacks for transformers-5.x-saved checkpoints: sentence_zero_shot,
   reading, finetune, AoA x2) must be present.
2. Venv (scratch purges it — rebuild, don't repair):
   `module load 2024 Python/3.12.3-GCCcore-13.3.0 CUDA/12.6.0`;
   `python -m venv /scratch-shared/$USER/babylm-eval/venv_eval` + activate;
   `pip install torch==2.7.0 --index-url https://download.pytorch.org/whl/cu126`;
   `pip install -r strict/requirements.txt`
3. Eval data (from `~/babylm-eval/strict`, venv active, HF_TOKEN exported):
   `python -m scripts.download_evals`
   `python -m evaluation_pipeline.global_piqa.dl`   # separate downloader
4. Checkpoint branches, once per model repo:
   `python scripts/mint_submission_branches.py --repo augustinian-babylm/<model> \
      --corpus_words 9923835 --steps_per_epoch 2574 --epochs 10`
   (19 `chck_*M` refs; maps in `eval/checkpoint_map_*.json`)

Per model (always `export HF_TOKEN=... && echo ${HF_TOKEN:0:6}` first;
submit from a clean login shell):
   `sbatch --export=ALL,HF_TOKEN,MODEL=augustinian-babylm/<model> \
      --job-name=full-<model> eval/eval_2026_full_rerun.slurm`
   (~10–14h; preflight data checks; per-stage output guards; evaluates
   revision `main` throughout — leaderboard convention, and verified
   within-noise of late checkpoints.)

Collate (login node, venv active):
   `bash scripts/collate_preds.sh augustinian-babylm/<model> mlm strict-small`
   -> `results/<model>/all_full_preds_and_fast_scores_mlm.json` (upload-ready)

Compare against the live leaderboard / analyze deltas:
   `python eval/compare_leaderboard.py --results_dir results`
   `python eval/analyze_official.py`

Gotchas: AoA fits are unseeded (scores near p=0.1 flip between runs;
AoA=0.0 means p>0.1 by design); global_piqa is n=100 (±10pt noise);
tqdm goes to `.err`; never sbatch from inside an srun allocation.

## B. VP-Swap (runbook)

Benchmark: [`vpswap_bb24/`](vpswap_bb24/) (see its README for construction
and format). Rebuild from scratch: `scripts/build_vpswap.py` (LLM-in-the-
loop; `--dry_run` first).

Score a model over the training trajectory (step0 + 19 chck revisions):
   `sbatch --export=ALL,HF_TOKEN,MODEL=augustinian-babylm/<model> \
      --job-name=vpswap-<model> eval/eval_vpswap.slurm`
   -> per-item JSONL under `results/vpswap/<model>/<rev>.jsonl`
   (~1h/model; raw JSONLs live on scratch, regenerable with this command).

Analyze (tables, figures, markdown summary):
   `python eval/analyze_vpswap.py --vision <model> --baseline <control>`

Sanity gate: step0 accuracy must be ~0.50 before interpreting anything
(see docs/entity_tracking_artifact.md for why we always check).

## Dynamics evaluation (secondary)

Fast zero-shot accuracy over all stepN checkpoints of all 12 models:
`eval_sweep.slurm` + `collect.py` -> `results_dynamics.csv`;
plots via `plot_dynamics.py` (figures in `plots/visioninit_*.png`).
